# 🚀 INICIO RÁPIDO: Múltiples Imágenes por Producto

## ⚡ En 2 Minutos

### Para Administrador

1. **Crea un nuevo producto** o **edita uno existente**
2. **En la sección de Imágenes:**
   - Carga hasta 3 imágenes (una a una)
   - O arrastra 3 imágenes a la vez
   - O pega con Ctrl+V/Cmd+V
3. **Verifica el preview:**
   - Primera imagen = Portada (etiqueta verde)
   - Números en esquinas (1, 2, 3)
4. **Guarda el producto**
5. ✅ **¡Listo!** Abre la tienda pública para ver la galería con rotación

---

## 📸 Pasos Detallados

### PANEL ADMINISTRATIVO

#### Paso 1: Abrir Formulario
```
Panel Admin → Productos → [Nuevo] o [Editar]
```

#### Paso 2: Sección de Imágenes
```
Desplaza hasta la sección "📸 IMÁGENES"

┌────────────────────────────────────────┐
│ 📸 IMÁGENES                            │
│ ┌──────────────────────────────────────┐│
│ │ Arrastra imágenes aquí o haz clic   ││
│ │ Máximo 3 imágenes, 1MB cada        ││
│ │                                      ││
│ │        [📁 Cargar imagen]           ││
│ └──────────────────────────────────────┘│
│ 0/3 imágenes cargadas                 │
└────────────────────────────────────────┘
```

#### Paso 3: Cargar Imágenes
**Opción A: Haz clic en botón**
- Click en "📁 Cargar imagen"
- Selecciona de tu computadora
- Repite hasta 3 veces

**Opción B: Arrastra**
- Abre carpeta de fotos
- Arrastra hasta 3 archivos a la sección
- Espera a que se carguen

**Opción C: Pega**
- Copia imagen (Ctrl+C)
- Pega en la sección (Ctrl+V)
- Repite hasta 3 veces

#### Paso 4: Verifica Preview
```
Después de cargar, verás:

┌──────────┬──────────┬──────────┐
│    1     │    2     │    3     │
│ [Foto]   │ [Foto]   │ [Foto]   │
│ Portada  │          │          │
│   ✕      │    ✕     │    ✕     │
└──────────┴──────────┴──────────┘

Observa:
• Imagen 1 tiene "Portada" (verde)
• Cada imagen tiene número
• Botón ✕ para eliminar
• Contador: 3/3 imágenes
```

#### Paso 5: Guarda
```
Scroll al final → Botón [Guardar]
```

## 👁️ PÁGINA PÚBLICA

### Tarjeta del Producto
```
Verás algo así:

┌──────────────────┐
│   [Portada]      │  ← Imagen 1
│                  │
│ Galaxy S23       │
│ Excelente...     │
│ $1,299.99        │
│ [Agregar Carrito]│
└──────────────────┘

Click en la imagen ↓
```

### Modal Emergente
```
Se abre un modal con:

┌─────────────────────────────┐
│ [Imagen Rotando...]         │
│                             │
│ ◀ [●●○] ▶  3/3             │
│                             │
│ Galaxy S23                  │
│ Descripción...              │
│ $1,299.99                   │
│ [Agregar al Carrito]        │
└─────────────────────────────┘

Qué ves:
• Primera imagen (portada) se muestra
• Rota automáticamente cada 2 seg
• Flechas ◀ ▶ para navegar manual
• Puntos ●●○ para ir directo a imagen
• Contador 3/3 muestra posición
```

### Controles en Modal

**Automático:**
- Imagen cambia cada 2 segundos
- Vuelve a la primera después de la última

**Manual (al pasar mouse):**
- Botón ◀ (Imagen anterior)
- Puntos ●●○ (Click para ir a imagen específica)
- Botón ▶ (Siguiente imagen)

## ⚠️ Cosas Importantes

### ✅ Permitido
- 3 imágenes de 500KB cada = 1.5MB total ✓
- Formatos: JPG, PNG, WebP, GIF ✓
- Cargar/pegar/arrastar ✓
- Eliminar individual ✓

### ❌ No Permitido
- Más de 3 imágenes ✗
- Imágenes > 1MB ✗
- Formatos raros (BMP, TIFF) ✗

### Errores Comunes
| Error | Solución |
|-------|----------|
| "Archivo demasiado grande" | Comprime imagen antes de cargar |
| "Máximo 3 imágenes" | Elimina una antes de cargar otra |
| "Tipo no soportado" | Convierte a JPG o PNG |

## 🎬 Casos Reales

### Caso 1: Actualizar Producto Existente
```
Tenías: 1 imagen de celular

Ahora:
1. Abre el producto para editar
2. Sección de imágenes muestra tu imagen antigua ✓
3. Carga 2 imágenes más
4. Total: 3 imágenes
5. Guardar
✅ Automáticamente se usa la galería con rotación
```

### Caso 2: Producto Totalmente Nuevo
```
1. Panel Admin → Nuevo Producto
2. Llena datos: nombre, precio, etc.
3. Carga 3 imágenes del producto
4. Guarda
✅ Producto aparece con galería en tienda
```

### Caso 3: Cambiar Imágenes
```
Tenías: 3 imágenes

Quieres cambiarlas:
1. Edita el producto
2. Elimina las 3 (botón ✕)
3. Carga 3 nuevas
4. Guarda
✅ Actualizadas
```

## 🔍 Troubleshooting

**P: Cargué 1 imagen, ¿muestra galería?**
R: No, solo muestra imagen sin rotación (sin botones).

**P: ¿Se pierden mis imágenes antiguas?**
R: No, se guardan junto con las nuevas. Sin problemas.

**P: ¿Por qué la rotación es 2 segundos?**
R: Es el estándar UX. Rápido para ver, lento para leer.

**P: ¿Puedo reordenar imágenes?**
R: Actualmente no. Elimina y carga en orden nuevo.

**P: ¿Funciona en móvil?**
R: Sí, totalmente. Botones más grandes en pantalla chica.

**P: ¿Funciona con Ctrl+V en todos lados?**
R: Solo en la sección de imágenes del formulario.
