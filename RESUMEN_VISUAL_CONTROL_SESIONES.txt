DATABASE (Firestore)
  └─ 📂 adminSessions (colección nueva)
     ├─ userId: UID de Firebase Auth
     ├─ deviceId: ID único del navegador
     ├─ isActive: boolean (true/false)
     ├─ lastActivity: timestamp
     └─ createdAt: timestamp

API ENDPOINTS
  ├─ GET /api/admin/sessions ........... Obtiene sesiones activas
  ├─ POST /api/admin/sessions ......... Valida o cierra sesión remota
  └─ DELETE /api/admin/sessions ....... Cierra sesión actual

FRONTEND COMPONENTS
  ├─ ActiveSessionsManager ............ Panel visual de sesiones
  └─ useSessionConflictDetector ....... Validación automática cada 60s

┌──────────────────────────────────────────────────────────────────────┐
│ 🔄 CÓMO FUNCIONA                                                    │
└──────────────────────────────────────────────────────────────────────┘

INICIO DE SESIÓN
  1. Admin ingresa credenciales
  2. Firebase Auth valida
  3. registerAdminSession() crea documento
  4. ↳ Cierra automáticamente otras sesiones
  5. Redirige a dashboard

EN EL DASHBOARD
  1. useSessionConflictDetector activo
  2. Valida cada 60 segundos
  3. Si isActive = false → Logout automático
  4. Redirige a login

CIERRE REMOTO
  1. Admin ve panel "Otras sesiones activas"
  2. Hace click en "Cerrar" para otro dispositivo
  3. API actualiza Firestore: isActive = false
  4. Otro dispositivo detecta cambio (< 60s)
  5. Logout automático
